## Preview
Extract the ZIP and open `index.html` in Chrome, Edge or Firefox.

## Publish free with Cloudflare Pages
1. Open https://dash.cloudflare.com/sign-up and create a free account.
2. In the dashboard choose **Workers & Pages** → **Create** → **Pages**.
3. Choose **Upload assets** / **Direct Upload** (not Git integration).
4. Project name: `medatlas` (if available).
5. Upload the extracted folder contents or the ZIP if the interface accepts ZIP.
6. Deploy. Cloudflare provides a public `*.pages.dev` address.

If the upload screen asks for a folder, extract the ZIP first and upload the folder containing `index.html` at its top level.

## Important
This is a structured starter library, not a complete MBBS textbook. Check facts against your current university syllabus, prescribed textbooks and updated clinical guidelines. Content is educational, not personal medical advice. No patient-identifiable data should be uploaded. Bookmarks and progress are stored only in the current browser, not synced to a cloud account.
